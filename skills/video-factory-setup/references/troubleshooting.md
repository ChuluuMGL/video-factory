# 检查与修复入口

先只读核对正在运行的 CLI 版本、项目、原 Setup session、stack 状态和准确错误码；再区分安装、Docker、飞书身份、Base 记录、n8n、模型调用与媒体回写。不要重装覆盖未知状态，不要因超时重发付费任务。需要完整的分层排障索引时阅读仓库 `docs/product/TROUBLESHOOTING.md`；单独下载 Skill 时可访问 https://github.com/ChuluuMGL/video-factory/blob/main/docs/product/TROUBLESHOOTING.md 。

- 安装中断：沿用原 session，核对已保存的步骤和固定发行版。
- 飞书授权过期：核对现有绑定和远端 Base，再发起一次本人授权；不重建表。
- 审核未推进：检查原任务行的状态、目标版本、事件队列与员工身份。退回时先保存意见再改状态；事后改意见不改已形成的回执。
- 停机期间改了审核状态：原表的选择不能代替飞书认证事件。先确认接收器恢复且版本未变；测试记录由本人恢复待审核、保存具体意见，再重新选择审核结果并回读事件与账本。真实客户任务先保留证据，不由 Agent 代签或直接改账本。
- 模型或附件结果不明：先对账现有供应商回执、媒体摘要和远端记录，再决定是否恢复写回；不自动重复付费请求。

新问题先搜索公开 Issues。Agent 可以写**脱敏草稿**交客户或实施人员审阅，不自动提交公开 Issue。不得把 API Key、App Secret、密码、IP、真实飞书 ID、客户资料、原始日志或未脱敏截图发到 GitHub；疑似漏洞使用私密报告。已关闭 Issue 也不能代替客户本机的升级与验收。
