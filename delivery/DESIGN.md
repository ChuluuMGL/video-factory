# 安装指南视觉与交付约定

面向客户管理员和内部实施同事，把第一次操作组织成“读懂产品 → 选择场景 → 下载 Skill / 复制指引 → 跟随 Setup → 得到交接”。页面不是工作台，也不假装是已经完成的 Setup。

视觉：暖白 #f7f7f1、墨绿 #192927、浅绿色 #d9f181；系统无衬线字体。唯一示意图是电脑、服务器和多个项目的关系，由 HTML/CSS 自绘，无外部素材。桌面非对称双栏，移动端先说明后操作再准备清单。字号 12/14/17/36/56，按钮至少 44px。只使用锚点滚动，尊重 reduced-motion；无跟踪脚本、远程字体或表单收集秘密。

交付内容由同次构建生成：网页、完整 Skill ZIP、可读 Skill 及 references、发行回执、客户指南。下载和复制是实际操作，不用伪造命令或空按钮。私有预览明确说明跨账户访问限制与附件备用路径。

验收：云端真实浏览器在桌面/手机检查无横向溢出、四种指引、复制、ZIP 下载及内部链接；比对 Skill 包与构建输入；安装包内容白名单。私人页面发布不等于客户已能访问，也不等于独立安装通过。
