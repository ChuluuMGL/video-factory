# 安装指南视觉与交付约定

阅读顺序：产品用途 → 既有项目真实成片 → Skill/CLI 安装 → 使用与维护。官网介绍整体业务、案例记录与服务；本页解释 Video Factory 并提供固定版本与 Agent 指引。日常从飞书 Base 进入，网页候选不作为默认安装步骤。

视觉沿用官网：深蓝黑 #02040a、白字、灰色正文、蓝色 #3b82f6，系统中文字体。桌面成片四列，手机两列；保留原画幅和原生播放器，点击后加载，不自动播放。无模拟工作台、占位视频、测试进展区或重复业务介绍。

案例直接引用用户指定的官网公开素材，保持匿名名称。它们是既有项目实践，不能作为当前安装包真实模型验收通过的证据。生产数量、示例成本、发布与自动回写等官网方案信息不移作安装版承诺。来源见 https://www.yueyu.tech/zh/solutions/ai-workflow-models 。

安装保持完整 Skill 下载、四种操作、常显指引、右上小复制按钮；版本、服务器要求和维护细节通过原生折叠控件提供。密码不在页面收集。默认由私有终端运行向导；临时安全输入页只在无法使用私有终端时开启，用后关闭，不绑定公开域名。客户文档、Skill 和页面说明需使用同一版本合同。

云端浏览器检查四种宽度、复制/降级/下载、内部链接、官网字体与四段视频的实际播放和来源。网页验收不等于客户可访问、独立安装或业务验收。完整设计方向见 docs/product/UI_DESIGN_DIRECTION.md。
