安装前准备

密码与密钥在私有终端填写。

  1. 01AI 助手能读取 Skill，并按授权连接服务器。
  2. 02Linux 服务器准备连接方式，环境由助手检查和安装。
  3. 03项目资料商品、参考图、飞书应用与审核人员。
  4. 04模型账户准备 API Key；生成任务单独确认。
给实施同事的服务器要求

自动环境准备支持 Ubuntu 24.04、x86_64、至少 4 GiB 内存。助手检查磁盘、网络和已有服务，并准备 Python、Docker 与 Compose。

使用与维护

安装会完成哪些配置？

检查服务器 → 配置首个项目并部署服务与 n8n → 设置管理员 → 连接飞书。Setup 到此结束；模型、真实任务和人工审核随后逐项验收。

安装后，团队怎样使用？

管理员启用项目执行和飞书事件，并核对真实推送；员工随后在同一飞书任务表看脚本和成片、填写意见并审核。这条流程仍待真实员工验收。

新增项目或帮助另一个客户，需要重装吗？

Skill 可以复用。同一客户新增项目时复用已有服务，另设项目资料与权限；不同客户分别部署。

中断、报错或升级，怎样处理？

选择“继续上次安装”或“排查问题”，把安装记录交给助手。续接保留已修改的商品和任务；升级前先备份。更新 Skill 不会自动升级服务器。

模型和费用怎么配置？

当前接入 DeepSeek Flash 和 MiniMax H3，使用客户自己的 API 账户。安装不会调用模型；每次生成需确认，结果需人工审核。
