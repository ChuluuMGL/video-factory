安装前准备

密码与密钥在私有输入窗口填写。

  1. 01AI 助手能读取 Skill，并按授权连接服务器。
  2. 02Linux 服务器准备连接方式，环境由助手检查和安装。
  3. 03项目资料商品、参考图、飞书应用与审核人员。
  4. 04模型账户准备 API Key；使用远程审核入口时，还需域名和证书。
给实施同事的服务器要求

自动环境准备支持 Ubuntu 24.04、x86_64、至少 4 GiB 内存。助手检查磁盘、网络和已有服务，并准备 Python、Docker 与 Compose。

使用与维护

安装会完成哪些配置？

检查服务器 → 部署服务与 n8n → 设置管理员 → 连接飞书与模型 → 配置首个项目并验收。你提供信息和授权，助手逐步执行。

安装后，团队怎样使用？

飞书表格整理商品与来源任务；客户服务器执行生成并保存结果。产品附带审核入口，用于查看脚本、视频和修改意见。生成结果目前不会自动写回飞书。

新增项目或帮助另一个客户，需要重装吗？

Skill 可以复用。同一客户新增项目时复用已有服务，另设项目资料与权限；不同客户分别部署。

中断、报错或升级，怎样处理？

在上方选择“继续上次安装”或“排查问题”，把安装记录交给助手。升级前先备份；更新 Skill 不会自动升级服务器。

模型和费用怎么配置？

当前接入 DeepSeek Flash 和 MiniMax H3，使用客户自己的 API 账户。安装不会调用模型；每次生成需确认，结果需人工审核。
