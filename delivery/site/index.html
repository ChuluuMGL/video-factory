目前哪些路线可完成？

Skill 提供三条并列路线：一是 v0.3 无 n8n 本机常驻路线（macOS / Linux，Python 3.11+），一键建立独立运行目录、自动托管参考图并支持增量改配置与用户级后台启停；二是便携路线（Mac、Windows、Linux），安装本机 n8n 或连接已有 Node.js/Docker 实例（Cloud 实例尚未实测）；三是 Ubuntu 24.04 x86_64 服务器完整栈。查看完整安装说明 · 无 n8n 本机常驻指南。

使用与维护

可以不安装 n8n、不租服务器，直接在本机用吗？

可以。v0.3 提供 macOS / Linux 无 n8n 本机常驻路线（Python 3.11+）：跟着 Skill 一键创建独立环境与 vf-setup、vf-run、vf-agent 启动器，无需安装 n8n 或 Docker；支持从普通目录自动校验并私有托管参考图、停机增量更新商品与成员配置，以及 launchd / systemd 用户级常驻启停。另保留零密钥假模型演练模式供纯本地预演。本页随附的 a41 固定 Linux 归档未内置该脚本，需使用已核验的 v0.3 版本或核心包；环境安装、项目配置、飞书授权、付费执行与真人验收分别确认，不会覆盖已有 n8n。

安装会完成哪些配置？

识别环境与选择路线 → 安装独立运行目录或接入 n8n → 保存首个项目配置与私有凭据 → 本人飞书授权并核对原任务表。无 n8n 本机常驻、已有/便携 n8n、Ubuntu 完整栈均可按需选择；付费模型执行、后台常驻和员工表内审核随后逐项独立确认。

安装后，团队怎样使用？

商品资料和创作要求放在飞书任务表；配置完成后，指定负责人核对并确认单次费用计划，再生成脚本。员工在原表查看脚本和成片、填写意见并审核。不同员工的权限隔离仍待真实验收。

新增项目、改商品或补参考图，需要重装吗？

不需要重装。v0.3 本机常驻路线停机后可直接增量更新商品、卖点、参考图与成员，也可为纯脚本项目补配视频，历史任务和加密凭据保留；同一客户新增项目复用已有环境与服务，不同客户分别部署。

自己的 Codex 能帮忙排障吗？

可以。选择“排查问题”，将私有安装记录和任务编号交给已获你授权的助手。它会先检查原项目，再说明修复办法；重新生成或停机需要你确认。

中断、报错或升级，怎样处理？

选择“继续上次安装”或“排查问题”，把安装记录交给助手。续接保留已完成配置；密码和密钥在私有输入处填写。升级前先备份，更新 Skill 不会自动升级服务器或本机运行环境。

关闭终端后还能运行吗？

可以。v0.3 无 n8n 本机常驻路线通过 local-service 显式生成权限 0600 的 macOS launchd 或 Linux systemd 用户服务文件，支持 start、status、stop 启停，不静默注册开机自启或失败无限重试；配置或账本变更后重新核对摘要并刷新模板。便携 n8n 路线另提供自启管理（Mac、Windows 登录后启动，Linux 系统服务可开机启动，已有 n8n 不被接管）。电脑休眠或退出当前系统用户会暂停用户级服务；退出并重新登录的真人验收仍待单独记录。

模型和费用怎么配置？

当前本机常驻内核与固定发行包接入 DeepSeek Flash 与 MiniMax H3。使用客户自己的 API 账户；密钥配置不生成内容，每次生成单独确认，结果在飞书审核。指定负责人逐条确认费用；更换模型或接口后重新确认计划。已完成单账号真实验收；第二账号权限仍待验。GPT、Gemini、MiniMax 文本、千问、豆包及可灵、Seedance、万相视频仍需独立验收；Seedream 是图片模型，也尚未接入固定包。旧项目案例不代表这些接口已进入正式安装包。

无 n8n 本机常驻引擎（v0.3）

不会搭 n8n、不租服务器的 macOS / Linux 用户，可由 Skill 引导一键创建独立 Python 环境、SQLite 加密账本与启动器：本人在私有终端隐藏录入密钥，参考图自动校验并复制到私有素材区，停机可增量修改商品与成员或补配视频。默认以只读模式常驻，支持 launchd / systemd 用户级启停与受限 Codex / 工作台接入；飞书身份授权、单次付费模型执行与团队人工验收彼此独立。详见 本机无 n8n 常驻安装与配置指南 ↗（a41 固定服务器包未内置，按 v0.3 核验版本获取）。
