## 剩余验收安排

先完成不依赖人员与凭据的修复、代码审查和云端合成检查。需要真实账号、现有管理员授权、付费计划或操作者时，明确指出具体阻塞；不把“技术收尾”写成所有功能已完工。

真人安装使用 [独立验收工作单](OPERATOR_ACCEPTANCE.md)，第二账号安排在最后。已完成的模型请求与原失败记录保留；未知请求先对账，不为补验收自动重发。原始身份、客户配置、供应商回执及运行日志留私有环境，公开仓库只保留脱敏结论。

当前产品仍是 Skill / CLI 安装、飞书原表操作、客户自己的 n8n 执行；没有新增员工门户。发布维护及后续功能分别记录，alpha 发布不代替上述尚未完成的验收。
