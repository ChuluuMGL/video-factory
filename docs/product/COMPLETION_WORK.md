## 当前版本的真实验收

跟踪：[验收 #8](https://github.com/ChuluuMGL/video-factory/issues/8)。

- [ ] 在隔离 Ubuntu 24.04 主机从 a32 固定包完成终端 Setup、服务启动和真实飞书 Base 绑定。既有 Ubuntu 22.04 测试机上的 a32 CLI 安装仅证明包可用，不能代替此项。
- [ ] 新测试 Base 与实际模型跑通脚本返工、单次视频生成及下载；记录费用和供应商回执。
- [ ] 显式启用 Base 结果同步，核对真实应用最小权限、附件上传及回读。
- [ ] 第二个真实项目接入，验证共享服务和项目隔离。
- [ ] 不同真实员工登录、越权拒绝、撤权与会话失效。
- [ ] 非作者独立安装、备份恢复与客户接管签收；结束后处理临时资源。

实施 Agent 负责资源准备、版本校验、技术执行及脱敏回执。实际员工负责本人身份与业务审核，独立安装者负责开箱体验；不能由实施 Agent 代替这两项签收。默认 CLI/飞书交付不要求产品业务域名；缺少人员或私密输入时先完成不依赖它们的工作，不启动空等的计费环境。
