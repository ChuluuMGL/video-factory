# 第一次测试与让 Agent 帮你排障

适用于已有 Video Factory 项目。请安装人员先填写客户自己的交接记录；以下是通用步骤，不表示你的项目已启用。仓库地址不会自动赋予 Codex 服务器或飞书访问权限。

## 先确认现在能做什么

请查看交接记录中的三项：**商品同步是否启用、费用入口是否启用、首次生成是否通过**。未启用的功能不会因你修改状态而自动开始；先联系安装人员，不要反复点击或手工打开全部 n8n 工作流。

只有连接完成时，可以先填写真实商品、建立关联任务和阅读指南。不要覆盖演示记录，不把没有参考图的虚拟商品当作可直接做图生视频的任务。

## 第一次完整测试

一次只用一个商品、一条新任务；按实际字段名称操作。下列流程须由安装人员确认入口就绪后执行。

| 步骤 | 你做什么 | 成功后应看到什么 |
|---|---|---|
| 1. 准备商品 | 在商品资料（SKU）填唯一 SKU、名称、规格、卖点、禁用表述、资料版本，上传自己的参考图 | 保存到云端；信息符合真实商品 |
| 2. 建立任务 | 新建唯一任务编号，关联一个 SKU，选择“资料待同步” | 已启用同步时变为“资料待确认”，任务出现本次商品资料和版本 |
| 3. 核对资料 | 查看任务内的商品资料、版本、图和创作要求 | 输入正确；有错误先修正或新建任务，不继续付费 |
| 4. 准备脚本计划 | 选择“申请脚本计划” | “费用待确认”，显示本次模型、输入、调用上限及确认编号 |
| 5. 负责人确认 | 指定负责人核对计划，在费用确认编号中填入本次编号并保存 | 本人身份核验后执行；随后脚本写回，“脚本待审核” |
| 6. 审核脚本 | 满意选“脚本通过”；返修先保存具体意见，再选“脚本退回” | 表中保留对应版本和决定；不因此自动生成视频 |
| 7. 单独确认视频 | 按所选模型核对首帧格式/数量，申请视频计划，由负责人另行确认 | 有视频任务编号，状态推进到“视频待审核”，可打开视频 |
| 8. 审核视频 | 查看结果，通过或保存具体返修意见后退回 | 决定保存在原任务；返修需新计划，不自动重复收费 |

模型可能排队，耗时由平台决定。没有出现预期结果时，记录任务编号、操作时间、当前状态和脱敏错误交给 Agent；不要清空执行编号、费用计划或连续提交新任务。商品资料更新不会自动改写旧任务的快照；新制作使用新任务。

## 把下面这段话交给自己的 Codex

> 请使用 Video Factory Setup Skill，先读取我授权的私有安装交接记录，核对实际主机、n8n 地址、项目和运行版本。排查任务「填写任务编号」从「填写操作时间」开始卡在「填写状态」的原因。先做只读检查：原飞书记录、n8n 工作流启用情况、事件与执行回执、已有模型任务；不要重新安装、清空账本或重新生成。报告原因、证据和建议修复步骤。需要新的费用、权限、数据删除或服务器重启时先让我确认。修复后核对原任务的实际结果。

Codex 需要客户授权的连接方式才能操作；只读 GitHub 能得到方法，不能查看你的私有执行状态。不要将密码或 Key 粘到聊天。续接使用原目录和项目，先读对应版本的说明；更新 Skill 不等于升级服务。

## 用户先看这几项

- 保存没反应：点击别处，确认飞书保存到云端，再查看交接记录是否已启用该入口。
- 401：让 Agent 核对 Key 所属平台、实际接口域名和模型区域，不反复换 Key 或猜域名。
- 余额/限流：核对对应平台账户与任务回执，不能认定失败就没有收费。
- 生成中/查询失败：优先查询已有任务，禁止重复生成；已有结果但未写回时恢复写回。
- n8n 打不开：先启动自己的隧道入口；日常审核在飞书，普通员工不需要编辑 n8n。
