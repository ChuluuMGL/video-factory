# 产品交付检查

本轮对象：新私有仓库 ChuluuMGL/video-factory，候选 a27。原仓库保留，不公开代码。所有运行测试在 GitHub 云端；不启动 ECS，不提交模型，不修改生产 Base。

客户打开页面，知道用途、准备内容和安装后所得；取得完整 Skill 交给 Agent。Agent 选择首次部署、新项目、续接或诊断，分阶段问答、安全交接秘密、执行和回读，最后提供入口及交接。新增项目不重装已有服务，不同客户不串用配置。

## 验收顺序

1. 用本次发行回执生成页面、Skill 和校验文件。
2. 云端 Chrome 验证页面操作与 Skill 内容一致。
3. 同一包在断网云端验证引导入口、版本回读、重复安装及拒绝不安全输入。
4. 已安装 CLI 继续执行 PTY、浏览器、双项目、PostgreSQL、容器及升级恢复回归。
5. 全部通过后创建固定私有 Release，镜像与 CLI 同次构建。
6. 发布私有指南预览，回读部署结果。跨账号访问与真人操作仍独立验收。

同事开始前，交付者必须准备可访问页面、安装包读取权限或已核验离线包、完整 Skill、安全输入渠道及准确测试服务器。缺项由交付者补，不让同事猜命令。范围先限于安装和脚本流程，不称为生产交付。
