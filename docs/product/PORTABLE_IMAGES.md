# Seedream 视频参考图（源码候选）

此路线为视频制作准备首帧或参考图，不新增网页工作区。它不在 a38 固定包内，真实 Seedream 调用仍需独立验收。

在完整 Skill 的 `welcome` 中选择配置 Seedream 图片流程。当前固定为火山方舟北京 `doubao-seedream-5-0-lite-260128`，一张 2K 图片、保留水印、关闭组图，不自动重试。Key 在终端隐藏输入，单独存入 n8n 加密凭据库；不会自动挪用 Seedance 或其他项目的 Key。续接不重复输入已保存的 Key。

1. 给项目原表补齐字段，保留已有内容。填写「商品资料」「图片要求」，在「参考图附件」放一张 PNG/JPEG 原图（最多 10 MiB）。
2. 把状态选为「申请图片计划」。指定负责人在飞书核对模型、图片用途、单次调用和费用账户，然后填写该计划的「费用确认编号」。
3. 仅提交一次生成。图片原始字节先保存到 n8n 执行账本，再上传到此 Base 的「生成图片」附件，回读确认后状态为「图片待审核」。原参考图不覆盖。
4. 在飞书选择「图片通过」或填写意见后「图片退回」。返修使用新任务保留原图和回执。选定图片后，将其放入视频任务的「参考图附件」，再单独申请视频费用计划；图片审核不会自动付费生成视频。

只有经过真实负责人零费用验收并显式启用的流程才接受付费确认。首次配置仅导入关闭流程；手动调试入口仍需要 `--experimental-manual`，并保留项目执行账本。

## 中断处理

- `busy`：模型是否接收请求尚未确定。保留账本，与供应商对账，禁止重新提交。
- `image_ready`：原图已保存、尚未尝试上传。`connect --flow recover-image` 导入无模型恢复流程，检查原任务未变后上传；随后运行普通 `recover` 将已保存附件回写原行。
- `image_uploading`：上传是否成功不确定。保留原始图片及原任务，不自动再上传或重新生成；先核对飞书回执。
- `result_ready`：附件 token 已保存。普通 `recover` 只回写原任务并核对实际附件 token，不再调用模型或上传。

流程拒绝覆盖之后修改的商品资料、图片要求、参考附件、审核状态或结果。不同供应商/区域的凭据与费用计划不能混用。保存成功不代表图片业务审核通过。

默认 n8n Data Tables 需要足够容量保存单张 Base64 图片（最多约 14 MiB，加上回执）；图片成功上传后账本替换为附件回执。若存储失败，停止并核对原请求，不自动重复付费。

接口依据：[火山方舟图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh&redirect=1)、[飞书上传素材](https://open.feishu.cn/document/server-docs/docs/drive-v1/media/upload_all)。实际模型输出与附件权限仍以独立验收回执为准。
