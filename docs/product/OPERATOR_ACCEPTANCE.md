# 独立安装与真实验收工作单

这份工作单给实际安装同事或客户使用。自动化云端演练只能证明指定步骤可执行；由开发者脚本代填问题不算非作者真人验收。不要填写或回传密码、App Secret、API Key、私钥或一次性管理员链接。

## 先确定本次对象

| 项目 | 由实际操作者填写 |
|---|---|
| 操作者、日期、是否参与开发 | 尚未指定 |
| 客户组织 / 部署 / 项目 ID | 尚未指定 |
| 专用测试主机或实例 ID、SSH 用户、已核对主机指纹 | 尚未指定 |
| 发行版本、来源提交、归档/清单 SHA256、通过的 Actions | 取自可信交付记录 |
| 测试 Base 名称及位置（新建），或已有非生产 Base；租户和 App ID | 尚未指定 |
| 提交人、脚本审核人、视频审核人的飞书用户 ID | 尚未指定 |
| CLI 版本目录、stack 目录、私有 session 目录 | 使用三个独立路径 |
| 实测任务、模型账户、允许的付费提交与重试范围 | 真实生成前单独确定 |

原四项目及旧 ECS 不自动成为本次目标。未确定主机时只做发行包检查；未确定真实飞书对象时不申请业务授权；没有明确任务范围时不提交模型。

## 仅照交付文件执行

1. 从可信交付记录核对归档和清单摘要，阅读发行包 `INSTALL.md`。准备客户 Linux x86_64、Python 3.12 + venv、root、本地 Docker/Compose 和容量。不要在管理人员 Mac 上运行服务测试。
2. 在 root 私有目录解压；用安装命令安装到新的独立版本前缀。记录实际 CLI 版本及 `cli_installed` 回执，不将它记作服务启动。
3. 建立外部私有 session 目录。将已安装前缀中的 `release/templates/products.json` **复制到自己的私有目录**，修改 SKU、商品名称、规格和事实来源。模板是一条虚构商品，不能当实际商品；不要直接编辑校验包。四个字段均必填，一至一百条，不能添加 Key/密码。
4. 在自己的私有终端运行 `setup-run`。从空 session 按问题填写；先退出一次，再用相同命令继续。本轮选择默认 `create` 并填新测试 Base 名称；无需提前建表。
5. 对照当前主机、客户/项目、目录和 SKU 数核对安装摘要。先选“不”，确认服务未安装；再次运行后明确确认，设置管理员密码并等待服务/项目回读。
6. 选择 test、存放位置和提交人（绑定路径才填表/字段 ID）。隐藏输入客户 App Secret 并确认保存到客户 vault。打开接入窗口，以真实飞书用户授权，核对租户、项目、字段、商品及两条测试任务后确认，回读实际 Base/表/字段/记录 ID；再续接一次，确认无重复创建。没有确认保存的窗口到期应显示待完成。
7. Base 所有者给测试员工授予所需表格访问权限；本工具不自动分享 Base。启动员工窗口，分别用真实人员验证自己的项目和审核角色。管理员链接不能给员工共享。远程浏览器只使用可信 SSH 同端口隧道；不裸露公网端口。
8. 记录每处卡点：所在问题、固定错误码、预期/实际结果、是否查阅额外源码或需要开发者代做。必要截图先去除账号敏感信息；不要录制秘密输入。仅能靠开发者补步骤完成，应标记“需改进”，不写成自助安装通过。

## 分阶段记录结果

| 阶段 | 必须回读的证据 | 初始结果 |
|---|---|---|
| CLI 安装 | 版本、提交、包摘要、依赖及重复安装回执 | 未执行 |
| 服务启动 | runtime / PostgreSQL / n8n 状态，主机入口和实际目录 | 未执行 |
| 项目配置 | 项目 ID、SKU 数和输入事实对应，续接无重复项目 | 未执行 |
| 真实飞书接入 | 当前租户/用户、目标表字段、确认绑定成功 | 未执行 |
| 员工工作流 | 至少两任务，真人脚本退回→新修订→再审核 | 未执行 |
| 真实视频任务 | 单一路线授权范围、供应商 ID、媒体回读及人工审核 | 未执行 |
| 故障恢复 | 约定停机范围内完成重启、备份及独立恢复，核对权限 | 未执行 |
| 交接 | 客户保管账户/密钥/备份；支持权限已撤销；最终服务状态 | 未执行 |

任务实际运行、供应商技术通过和人工商业质量结论分别填写。提交结果未知时保留原任务及回执，先核查，禁止为了得到成功结果自动重发付费调用。

## 自动化演练能说明什么

a20 候选在 GitHub 云端，用同一发行包安装出来的 CLI 从空 session 走真实终端问题、退出/续填、SKU 模板及错误文件重试、已有 Base 默认值、安装前取消，再进行容器安装和后续原检查。测试输入、飞书授权和供应商均是合成数据；它不填写上述真人验收表，也不证明实际安装同事无需开发者协助。
