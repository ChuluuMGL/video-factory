# 便携项目原地升级

适用于 a38 及以后包含 `portable_upgrade.py` 的完整 Skill。a37 及更早固定包不含此命令；请先下载已发布的新版本，保留原项目绑定目录。

升级复用原 n8n、Base、工作流 ID 和凭据引用，不重新安装 n8n。使用保存项目绑定的原目录（欢迎向导通常为 `~/.video-factory/n8n/bindings`），不要新建项目绕过模板校验。

1. 停止本项目事件接收器，暂停本项目原工作流。保留其他项目。
2. 核对执行账本：进行中或结果未知的调用先对账；尚未确认的费用计划用原 `approval-cancel --expect-plan ...` 明确取消。已消费回执保留。
3. 使用新版 Skill 中的脚本预览：

   ```sh
   python3 scripts/portable_n8n.py --root /原绑定目录 upgrade-plan --url https://你的-n8n --project 原项目
   ```

4. 核对返回的工作流数量、变更数和计划摘要。确认后运行：

   ```sh
   python3 scripts/portable_n8n.py --root /原绑定目录 upgrade-apply --url https://你的-n8n --project 原项目 --expect-plan 完整计划摘要
   ```

API Key 在隐藏终端输入，不写进命令。原模板、本次变更和回执保留在原绑定目录的私有 `upgrade-*.json` 文件中；不要提交这些文件到 GitHub。更新不调用生成接口，不写 Base，不导出凭据，不清理历史结果。

升级后工作流保持关闭。先核对原项目和做零费用验收，再明确恢复事件接收器及审核入口。更新时如有网络超时，续接同一计划只读取远端结果；若无法证明已成功，不会自动重发 PUT。此时保留检查点，人工核对。不要删除绑定或账本来重试。

支持本产品记录的标准便携工作流。手工修改的流程、自定义接口、记录缺失或作用域不同会停止，不覆盖客户定制。服务器完整栈仍使用其原升级与备份步骤。
