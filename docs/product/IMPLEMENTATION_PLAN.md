# 产品交付顺序

1. 产品定义与仓库整理：固定产品边界、用户入口、目录白名单和历史保留。
2. 交付页面与完整 Skill：四场景、真实获取地址、逐步 Setup、结果与维护。
3. 固定发行衔接：同版源码、归档、Skill、镜像、校验与全部云端检查。
4. 开箱安装：补齐依赖准备、安全输入、权限获取和首次/第二项目的从零演练。
5. 项目启用：选定模型通用路线、真实任务回执、审核、恢复及持续员工入口。
6. 非作者验收与客户交接；通过后再决定生产可用范围。a31 已按 MIT 公开测试发行，开源不代表生产验收完成。

每一阶段提供真实产物与回读，不把阶段完成合并成生产就绪。检查表见 DELIVERY_ACCEPTANCE.md。所有运行检查在云端，Mac 仅编辑、静态审阅、Git 与小型证据读取。
