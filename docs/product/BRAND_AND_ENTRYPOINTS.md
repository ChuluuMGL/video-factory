# 官网品牌与产品入口

2026-10-06。官网产品页已经上线；CLI/Skill 安装与飞书日常使用不要求业务子域名。形态与验收边界见 [产品决定](PRODUCT_SHAPE.md)。

## 入口关系

1. 已上线的 `https://www.yueyu.tech/zh/solutions/ai-workflow-models`：企业 AI 方案总入口。介绍场景、案例和服务；Video Factory 是其中的视频生产产品。官网的历史项目能力不能当作此安装包已经交付的功能。
2. 已上线 `https://www.yueyu.tech/zh/products/video-factory/`：产品说明、安装指南、完整 Skill、固定版本和 GitHub 入口。官网产品菜单将其排在首位；a31 源码和发行包可以匿名获取。
3. `video.yueyu.tech` 当前不作为安装或员工入口；即使域名已解析，也不能用它暴露临时 Setup 输入页。后续若确实需要网页产品，须单独定义用途和验收，不从 CLI 安装自动推出。
4. 客户自部署使用客户自己的域名，如 `video.customer.example`。无需由月瑀维护一个汇集客户账户、任务和 Key 的总服务器。静态安装文档可以公开托管，客户运行服务独立维护。

当前使用官网内产品页，不再另开重复介绍方案的产品子站。以后产品拥有独立文档体系、多个版本或专门品牌时，再考虑 docs/product 子域名并保留旧地址重定向。

## 当前部署限制

服务器、PostgreSQL 与 n8n 可在同一客户内复用。公开 a31 仍含早期常驻网页审核实现，后续候选又增加了门户和证书管理；这些不属于推荐的 CLI/飞书安装路径。本分支已拆出无公网端口的项目 runner，但 n8n 调度还须云端容器和真实业务验收。官网不嵌入密钥输入或管理操作。

## 品牌基准

以官网当前线上 AI 页的实际字体和样式为准（构建后的 CSS 文件名随官网发布变化）：深黑蓝 `#02040a`、白色文字、品牌蓝 `#3b82f6`、系统中文字体。

官网安装说明延续官网配色；私有 Setup 输入页只需清楚、安全，不承担产品展示。面板 `#0f1219`，次级区域 `#0f1623`，正文 `#ffffff`，说明 `#d1d5dc`，链接与焦点 `#93c5fd`。实心按钮使用更深的 `#2563eb` 配白字保证小字号可读性；状态仍用文字明确含义。

字体回退顺序与官网简体中文页一致，标题字重为 500；安装页主标题的响应式字号、行距和字距也与官网一致。正文和按钮保留适合安装操作的较大字号。具体参数和云端对照方法见 [界面设计说明](UI_DESIGN_DIRECTION.md)。

官网保留公司署名月瑀科技，GitHub 使用个人署名 Chuluu。a31 官网部署与响应式交互已验证，历史案例不作为当前安装版的业务验收证据；固定发行保持不变。
