# 官网品牌与产品入口

2026-10-01。以下 URL 规划是建议，未创建 DNS 或改动官网生产站。

## 入口关系

1. 已上线的 `https://www.yueyu.tech/zh/solutions/ai-workflow-models`：企业 AI 方案总入口。介绍场景、案例和服务；Video Factory 是其中的视频生产产品。官网的历史项目能力不能当作此安装包已经交付的功能。
2. 建议官网新增 `/zh/products/video-factory`：独立产品说明、安装指南、完整 Skill、版本和支持入口；从 AI 方案页链接进入。当前先使用受控安装预览，私有仓库与私有安装包不能包装成任何人可下载。
3. 建议内部验收使用 `vf-test.yueyu.tech`，内部正式使用 `vf.yueyu.tech`：客户服务器上的员工工作区。域名是规划，尚未确认可用或部署。测试、正式环境分开，官网不承接任务 API、账号会话或模型 Key。
4. 客户自部署使用客户自己的域名，如 `video.customer.example`。无需由月瑀维护一个汇集客户账户、任务和 Key 的总服务器。静态安装文档可以公开托管，客户运行服务独立维护。

先建设官网内产品页即可，不需要再开一个重复介绍方案的产品子站。以后产品拥有独立文档体系、多个版本或专门品牌时，再考虑 docs/product 子域名并保留旧地址重定向。

## 当前部署限制

服务器、PostgreSQL 与 n8n 可在同一客户内复用，员工工作区目前按项目部署。每个工作区绑定自己的 HTTPS origin 和宿主端口；多个项目直接占用同一 443 端口会冲突。可先使用不同 HTTPS 端口；统一域名项目选择器、自动反向代理路由、自动证书签发续期不在当前交付范围。不要因为共享一个根域名而把项目会话合并。官网只链接已经验收的入口，不嵌入密钥输入或管理操作。

## 品牌基准

以官网当前线上 AI 页的实际字体和样式为准（构建后的 CSS 文件名随官网发布变化）：深黑蓝 `#02040a`、白色文字、品牌蓝 `#3b82f6`、系统中文字体。

四个产品界面保持同一配色：安装指南、私有 Setup、飞书授权、员工审核。面板 `#0f1219`，次级区域 `#0f1623`，正文 `#ffffff`，说明 `#d1d5dc`，链接与焦点 `#93c5fd`。实心按钮使用更深的 `#2563eb` 配白字保证小字号可读性；状态仍用文字明确含义。保留原生光标、键盘焦点与离线字体，工作页面不增加官网装饰动画。

字体回退顺序与官网简体中文页一致，标题字重为 500；安装页主标题的响应式字号、行距和字距也与官网一致。正文和按钮保留适合安装操作的较大字号。具体参数和云端对照方法见 [界面设计说明](UI_DESIGN_DIRECTION.md)。
